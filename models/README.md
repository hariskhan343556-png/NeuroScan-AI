# Model Weights Directory

Place the trained model file `NeuroNova_AI_model.pth` in this directory:

```text
models/
└── NeuroNova_AI_model.pth
```

### How to obtain the model weights:
1. Open and run `model/MRI-Brain-Tumor-Classifier.ipynb` in Google Colab or Kaggle (with GPU acceleration).
2. Download the saved checkpoint `NeuroNova_AI_model.pth`.
3. Put `NeuroNova_AI_model.pth` in this `models/` folder.
4. Restart the FastAPI server.
